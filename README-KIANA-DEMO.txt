CitaloPlan — Kiana Student Profile Demo v9
=======================================

نسخه دمو برای اجرای مستقیم در VS Code / Live Server

صفحات اصلی:
- index.html          صفحه اصلی فعلی سیتالوپلن
- login.html          ورود دانش‌آموز
- profile.html        پروفایل شخصی دانش‌آموز
- major.html          یک صفحه مشترک برای همه رشته‌ها با query string

ورود دمو:
Username: kiana
Password: Kiana@1404

نکته مهم امنیتی:
این لاگین فقط برای دمو است و امنیت production ندارد.
برای انتشار واقعی چنددانش‌آموزه باید آن را به Supabase / Firebase / backend واقعی وصل کنید.

معماری داده:
- data/majors-data.js
  اطلاعات عمومی رشته‌ها؛ فقط یک بار نگهداری می‌شود.
- data/students.js
  پروفایل دانش‌آموزها و Shortlist هر نفر.
- data/student-major-insights.js
  تحلیل اختصاصی Student × Major؛ برای Kiana تحلیل‌های RIASEC/CDDQ فعلی اینجاست.

کارنامه تصویری Kiana:
assets/kiana-riasec-cddq-poster.png

اجرای محلی:
1) فولدر پروژه را در VS Code باز کنید.
2) افزونه Live Server را نصب/فعال کنید.
3) روی index.html راست‌کلیک کنید و Open with Live Server را بزنید.
4) از «ورود دانش‌آموز» وارد شوید.
5) با kiana / Kiana@1404 وارد پروفایل شوید.

نمونه URL رشته:
major.html?student=kiana&major=physio
major.html?student=kiana&major=medicine

برای دانش‌آموز جدید:
1) فقط رکورد جدید در data/students.js بسازید.
2) Shortlist او را تعیین کنید.
3) تحلیل‌های اختصاصی او را در data/student-major-insights.js اضافه کنید.
4) اطلاعات عمومی رشته‌ها را دوباره کپی نکنید.

فونت:
پروژه B Koodak را با local() درخواست می‌کند.
اگر روی سیستم فونت B Koodak نصب نباشد، مرورگر به Tahoma/Arial fallback می‌کند.
فایل فونت داخل این پکیج اضافه نشده است.

انتشار آنلاین:
برای نسخه استاتیک دمو می‌توانید فولدر را روی Netlify / Vercel / GitHub Pages منتشر کنید.
برای نسخه واقعی دارای حساب دانش‌آموز، قبل از انتشار عمومی login را به backend/Auth واقعی منتقل کنید.
